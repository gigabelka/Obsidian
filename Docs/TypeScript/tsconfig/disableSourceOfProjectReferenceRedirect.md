# `disableSourceOfProjectReferenceRedirect`

When working with [composite TypeScript projects](../project-config/project-references.md), this option provides a way to go [back to the pre-3.7](../release-notes/typescript-3.7.md#Build-Free Editing with Project References) behavior where d.ts files were used to as the boundaries between modules.
In 3.7 the source of truth is now your TypeScript files.
