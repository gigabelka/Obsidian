# Documentation Index

Central index of all programming documentation in this vault.

## Technologies

### React

Full offline copy of the official [react.dev](https://react.dev) documentation, converted to clean Markdown.

- **Index:** [React/INDEX.md](React/INDEX.md) — full table of contents (Learn + API Reference)
- **Tutorial / guides:** [React/learn/](React/learn/) — "Learn React" from quick start to escape hatches
- **API Reference:** [React/reference/](React/reference/) — Hooks, Components, APIs, react-dom, rules, RSC
- **Error codes:** [React/errors/](React/errors/) — production error decoder pages
- **Warnings:** [React/warnings/](React/warnings/) — common warning explanations

When searching for React information, start with [React/INDEX.md](React/INDEX.md) to find the right page, or grep the `React/` folder directly.

## Vault structure

- Each technology lives in its own top-level folder (`React/`, ...).
- Each folder contains an `INDEX.md` with the full table of contents for that technology.
- All files are plain Markdown with relative links — safe to read and search with any tool.
