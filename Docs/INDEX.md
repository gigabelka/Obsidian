# Documentation Index

Central index of all programming documentation in this vault.

## Technologies

### React

Full offline copy of the official [react.dev](https://react.dev) documentation, converted to clean Markdown.

- **Index:** [React/INDEX.md](React/INDEX.md) — full table of contents (Learn + API Reference)
- **Tutorial / guides:** [React/learn/](React/learn/) — "Learn React" from quick start to escape hatches
- **API Reference:** [React/reference/](React/reference/) — Hooks, Components, APIs, react-dom, rules, RSC
- **Error codes:** [React/errors/](React/errors/) — production error decoder pages
- **Warnings:** [React/warnings/](React/warnings/) — common warning explanations

When searching for React information, start with [React/INDEX.md](React/INDEX.md) to find the right page, or grep the `React/` folder directly.

### TypeScript

Full offline copy of the official [typescriptlang.org](https://www.typescriptlang.org) documentation, converted to clean Markdown.

- **Index:** [TypeScript/INDEX.md](TypeScript/INDEX.md) — full table of contents
- **Handbook:** [TypeScript/handbook/](TypeScript/handbook/) — the main tutorial-style guide
- **Reference:** [TypeScript/reference/](TypeScript/reference/) — utility types, decorators, enums, JSX, etc.
- **TSConfig Reference:** [TypeScript/tsconfig/](TypeScript/tsconfig/) — one page per compiler option
- **Tutorials:** [TypeScript/tutorials/](TypeScript/tutorials/) — ASP.NET Core, Gulp, Babel, DOM, migration
- **Release notes:** [TypeScript/release-notes/](TypeScript/release-notes/) — what's new in every version
- **Modules Reference:** [TypeScript/modules-reference/](TypeScript/modules-reference/) — how TS models JS modules
- **Project Configuration:** [TypeScript/project-config/](TypeScript/project-config/) — tsconfig, project references, watch
- **Declaration files / JavaScript:** [TypeScript/declaration-files/](TypeScript/declaration-files/), [TypeScript/javascript/](TypeScript/javascript/)

When searching for TypeScript information, start with [TypeScript/INDEX.md](TypeScript/INDEX.md) to find the right page, or grep the `TypeScript/` folder directly. For compiler flags, grep `TypeScript/tsconfig/` directly (file names are flag names).

## Vault structure

- Each technology lives in its own top-level folder (`React/`, ...).
- Each folder contains an `INDEX.md` with the full table of contents for that technology.
- All files are plain Markdown with relative links — safe to read and search with any tool.
